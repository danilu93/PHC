# Pets Health Control (PHC)

**Pets Health Control (PHC)** is an academic software project focused on creating a digital veterinary record management system. The goal is to modernize the way veterinary clinics manage pet health records by providing a centralized platform where pet owners and veterinary staff can easily access medical histories, appointments, and treatment information.

> **Project Status:** Initial Prototype (MVP)

## About the Project

PHC was created as the first stage of a larger software development project. The current version is a **basic console application** designed to validate the core structure and logic of the system before expanding into a complete web and mobile platform.

The long-term vision is to provide a secure and user-friendly solution that improves communication between veterinary clinics and pet owners while replacing outdated paper-based processes with digital records. 

## Current Features

The prototype currently demonstrates the basic functionality of the system through a console interface.

- Basic pet information management
- Simple veterinary record handling
- Menu-based console navigation
- Initial project architecture and data organization

## Current Limitations

As this is an early prototype, several planned features are **not yet implemented**, including:

- Automatic appointment and treatment reminders
- Vaccination notifications
- Fully functional user authentication
- Role-based access control (Owner, Veterinarian, Administrator)
- Complete appointment scheduling
- Advanced search and reporting features

These features are part of the project's planned roadmap for future development.

## Future Development

The objective is to evolve PHC into a modern, cross-platform application.

### Planned Technology Stack

- **Backend:** Spring Boot (Java)
- **Web Frontend:** HTML, CSS, and JavaScript
- **Mobile Application:** Android (with future cross-platform support)
- **Database:** MySQL or PostgreSQL
- **REST API** connecting both web and mobile applications

### Planned Features

- User registration and login
- Role-based permissions
- Complete digital medical records
- Consultation, diagnosis, and treatment management
- Appointment scheduling
- Automatic reminders and notifications
- Secure access to pet health records
- Reporting and advanced search tools

## Project Goal

The primary objective of PHC is to develop a secure and organized digital platform for veterinary record management, making pet health information more accessible while improving administrative and clinical workflows. 

## Academic Notice

This repository is an **academic project** developed for educational purposes. The current implementation represents an initial prototype intended to demonstrate the project's foundation, with future plans to continue its development into a full-featured web and mobile application.
